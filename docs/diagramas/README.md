# Diagramas

Cada diagrama vive en su carpeta: la especificación (`<slug>.archify.json`) es la fuente y el HTML (`<slug>.html`) se genera desde ella con [Archify](https://github.com/tt-a1i/archify). Para cambiar un diagrama, edita la especificación y vuelve a generarlo con `archify deliver`; no edites el HTML. Prettier no toca ninguno de los dos.
